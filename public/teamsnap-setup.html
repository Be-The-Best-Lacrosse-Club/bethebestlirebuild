TeamSnap Setup

TeamSnap Authorization • Owner Only

This page connects the BTB website to your TeamSnap account so the Parent Portal's tournament schedule can pull live data. The TeamSnap app registration is one-time; token refreshes now run through BTB-OS without manually editing Netlify.

Step 1 — Register a TeamSnap App

  1. Go to auth.teamsnap.com and log in with your BTB TeamSnap account.
  2. Click your name (top right) → Your Applications → New Application.
  3. Fill it in:
    • Name: BTB Website
    • Description: Live tournament schedule for bethebestli.com
    • Redirect URI: https://www.bethebestli.com/.netlify/functions/teamsnap-callback
    • Scopes: read
  4. Submit. Copy the Client ID and Client Secret it gives you.

Step 2 — Reconnect From BTB-OS

Token updates are now handled automatically from BTB-OS. Do not copy TeamSnap tokens into Netlify manually.

Go to BTB-OS → Integrations → TeamSnap → Reconnect. After you approve TeamSnap, both Netlify projects update and deploy automatically.

Troubleshooting

  • "Not configured" error on the schedule page: Use the BTB-OS reconnect flow to refresh TeamSnap credentials.
  • "Redirect URI mismatch" on TeamSnap: The URI in the TeamSnap app must match exactly, including https://www. (not bare bethebestli.com).
  • No events showing: Your TeamSnap events need is_game = true and dates in the range. The function fetches May/June/July of the current year by default.
